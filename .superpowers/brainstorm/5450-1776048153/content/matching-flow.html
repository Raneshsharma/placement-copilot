Email → Application Matching Flow

How the system connects a new email to the right application card

1
New email arrives via Gmail sync
From: recruiter@accenture.com
Subject: Update on your Strategist application
2
Job Email Filter — Is this job-related?
✓ Has recruiter/company sender domain
✓ Subject/body contains job keywords
✓ Not a newsletter or calendar invite
→ Job email confirmed
3
3-Pass Matching (in order of confidence)
PASS 1 Thread ID match Confidence: 98%
Email thread ID matches existing application thread
→ Direct match: Accenture Strategist ✓
PASS 2 Recruiter domain match skip — already matched
Domain @accenture.com → existing Accenture applications
PASS 3 Fuzzy company + role match skip — already matched
"Strategist" + "Accenture" text matching against stored applications
4
Status Detection + Auto-Move
Email subject: "Update on your Strategist application"
Submitted
→
Interview ← triggered by "invite", "call", "schedule"
✓ Card auto-moved to Interview. Email added to timeline.
5
Low-confidence result?
If no match above 75% confidence, the email appears in a Needs Review queue. User reviews, confirms or corrects the match before any card is created or moved. Never auto-create on low confidence.
