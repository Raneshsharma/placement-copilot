Email → Status Classification

How the system maps email content to Kanban stages

Wishlist
User-added only — no email triggers this stage
Submitted
Keywords: "application received", "received your application", "confirming receipt", "we've received", "application submitted"
Under Review
Keywords: "under review", "reviewing your application", "your profile is being reviewed", "in the hiring process", "moving forward"
Interview
Keywords: "interview", "invite you to", "schedule a call", "would like to meet", "technical assessment", "phone screen", "video call"
Offer
Keywords: "offer", "extend an offer", "pleased to offer", "compensation", "start date", "offer letter"
Rejected
Keywords: "not moving forward", "decided not to proceed", "going with another candidate", "regret to inform", "unfortunately", "position has been filled"
Archived
User action only — manually archive old applications

Classification Behavior

  • Multiple keywords can fire — system picks the most advanced stage (Offer > Interview > Under Review > Submitted)
  • Keyword matching is case-insensitive and phrase-aware (avoiding false positives like "we are excited" inside a rejection)
  • Email must be matched to an existing application first — no orphan status changes
  • User can reclassify any auto-detected status via the detail panel
